# 投稿審查系統（Submission Review System）

## 專案介紹

本專案為期中作業，實作一個簡易的線上投稿審查系統，提供作者與編輯兩種操作介面。

## 使用技術

- HTML：建立網站結構
- CSS：設計網站介面
- JavaScript：處理投稿、編輯及審查功能
- localStorage：在瀏覽器本機儲存稿件資料

## 系統功能

### 作者
- 查看投稿清單與審查狀態
- 新增、編輯及刪除編輯中的稿件
- 將稿件送出審查

### 編輯
- 查看待審查稿件清單
- 查看稿件內容
- 通過或退回稿件

## 審查流程

1. 作者新增稿件，初始狀態為「編輯中」。
2. 作者送出稿件，狀態變成「審查中」。
3. 編輯審查後，可選擇通過或退回。
4. 通過後狀態為「已通過」；退回後重新變成「編輯中」。

## 執行方式

1. 下載專案中的 `index.html`。
2. 使用 Safari、Chrome 等現代瀏覽器開啟。
3. 選擇作者或編輯介面，即可操作系統。

本專案不需要安裝額外套件或資料庫。

## 注意事項

目前為前端展示版本，使用瀏覽器 localStorage 儲存資料，尚未實作真正的帳號登入、伺服器端權限驗證及多人共用資料庫。
